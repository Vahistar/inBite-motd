# inBite MOTD

A collection of MOTD banners kept as plain text files.
Every file is self-contained and meant to be used as-is: an SSH banner, an `/etc/motd` drop-in, or a remote splash fetched into a console by [fetchJAR](https://github.com/Vahistar/inBite-fetchJAR).

## What's inside

- `.txt` files in plain ASCII
- some banners include ANSI color codes, so they render in color wherever ANSI is supported (SSH, Windows Terminal, xterm.js, Pterodactyl)
